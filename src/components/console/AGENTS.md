# Console UI rules
- Scene.pixelMaster applies gain after REC compositing; cue snapshots and programmed layers stay unchanged.
- MoonLite uses documented TimoTwo GATT slot changes with full 512-slot initialization; UDP remains separate.
- Background discovery never changes the selected destination, preventing unintended output switches.
- GDTF imports preserve absolute offsets and unknown slots; declared CCT physical bounds drive encoding.
- Live-plot beam samples use an interpolated light texture and angular falloff rather than visible world-space tiles, preserving height-aware wall occlusion.
- ColourControls is shared by fixture, effect and live-plot controls to keep the CCT/crossfade/HSI ordering consistent; HexColourControls edits step and pixel palette colours.
- Live-plot openings reference stroke/segment indices and use height-aware ray intersections; remap their indices whenever walls are removed so saved openings stay attached.
- Live-plot edit history stores plot and light-control snapshots, grouping pointer gestures as single edits so undo does not step through every drag frame.
- PaletteEditor shares CCT/HSI/gel editing across fixture and pixel effects; generated pixel effects opt into custom palettes to preserve older saved looks.
- FixtureGlyph uses validated, normalized PatchedFixture.icon overrides edited through FixtureIconPicker; icons never change DMX modes.
- Plot camera state is an optional Scene.plot.view field and persists outside geometry undo history, keeping older saved projects compatible.
- Fixture grid columns use the available console container width rather than viewport width so the control panel cannot squeeze square tiles.
- Live-plot cameras are an optional Plot.cameras field; CameraView renders a perspective view with exposure from lens/iris/ISO (src/lib/plot-camera.ts).
- Camera projection uses the tested cameraBasis helper with plot Z-up coordinates so lens views remain upright at every yaw.
- Pixel preview auto-fits logical grid dimensions to a ResizeObserver-measured viewport; pan and zoom affect only the view, never pixel addressing or DMX output.
- Emergency blackout sits to the right of the master fader with an output-enabled bulb indicator; full group management and saved looks share the collapsible right rail so neither needs a view tab.
- Plot cameras use height-aware canvas placement and hit-testing; a selector keeps editing and confirmed removal reachable.
- Plot fixture/object/camera selection IDs stay separate; mixed moves and removals commit one snapshot for atomic undo.
- The DMX map fills its panel width as one fixed 32×16 band (DmxMap); on lg+ the fixture library/map sits in a right-side column beside the patch sheet, stacked below on narrow screens.
- All check marks use the shared ui/checkbox component so selection looks identical app-wide.
- Patch page is a console overlay, not a route, so it edits live fixture state.
- Number inputs use the shared NumberField (commit on blur/Enter) so fields can be cleared while typing without snapping to a value.
- Pixel preview framing stays local to PixelPanel and derives from the logical grid and measured viewport, keeping display changes independent of saved effects and output.
- The console toolbar layer (sticky Select all/Sweep/REC bar) sits above the fixture number badges, so scrolled numbers slide under it instead of painting over it.


- EffectsRail owns fixture/pixel effect saving and recall; ConsoleScreen shares the active pixel-layer ID with PixelPanel so the rail saves the layer being edited.
- Pixel map uses pixel-preview with the shared live frame and all active fixture IDs so REC overlap stays visible without changing output.
- Moving-head values live in PatchedFixture.beam; unset channels output GDTF defaults so shutters stay open. Library is sharded (library.json index) under the repo file limit.
- Console swaps and Patch drag insertion move whole fixtures without changing identity or settings. Patch displays canonical positions as read-only numbers; drag insertion changes keypad/PDF positions.
- Fixture FLASH and fader banks are output-only overlays in outFixtures, never mutating live fixture state; keypad numbers are console positions.
- GDTF library is curated by scripts/gdtf-curate.ts using src/lib/gdtf-curation.ts; exact model aliases dedupe profiles without merging distinct revisions, and only model-specific verified power may fill missing watts.
- Timeline (Scene.timeline, src/lib/timeline.ts) plays clips on free layers (top wins, no overlap within a layer). Pause and the end hold the current output; only Stop restores the pre-play state. Markers wait for GO; soundtracks live in IndexedDB (timeline-audio.ts).
